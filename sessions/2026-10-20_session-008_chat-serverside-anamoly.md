**The delta-rule lineage, precisely:**

- Linear attention (Katharopoulos et al. 2020): S_t = S_{t-1} + x_t y_t^T (outer product accumulate). Retrieval: S q.
- DeltaNet (Schlag, Irie, Schmidhuber 2021, "Linear Transformers Are Secretly Fast Weight Programmers"): S_t = S_{t-1}(I − β_t x_t x_t^T) + β_t x_t y_t^T — delta rule: *replace* the association for key x_t rather than add, mitigating interference/overwriting noise. Parallelized over sequence length by Yang et al. 2024 (arXiv:2406.06484, NeurIPS 2024) via the WY representation / chunkwise parallel form.
- Gated DeltaNet (Yang, Kautz, Hatamizadeh 2024; arXiv:2412.06464; ICLR 2025): adds a data-dependent decay gate α_t: S_t = α_t(S_{t-1}(I − β_t x_t x_t^T) + β_t x_t y_t^T)... roughly, combines Mamba2-style gating with delta rule, improving length extrapolation & associative recall.

**The RVA formal core**:

- Definition (Pin): a pin is a tuple p = (path, c, h, τ, m) where h = SHA-256(content c), τ timestamp/commit, m metadata (provenance, classification).
- Definition (Rehydration): given repo R (DAG of commits/objects), rehydration R(p) recomputes h from the object database alone: git show <commit>:<path> → hash → compare. Pin is *verified* iff h recomputes; *live* iff the object is reachable; *orphaned* iff recorded but not recomputable (mapping break); *self-pinned* iff pinned by an artifact inside its own content scope → excluded (well-foundedness: no self-reference).
- Theorem-ish (informal): under SHA-256 collision resistance and an append-only object store, any statement of the form "content c existed at commit τ with hash h" is verifiable by any party holding R alone, independent of any agent's memory — the involuntary-return criterion: content cannot be voluntarily suppressed by the current instance's state because it remains recomputable from R.
- Boot-restatement: at session start, the entity restates the current verified state (head hash, manifest, open questions); a mismatch = divergence alarm. **The missing-piece argument, stated honestly and sharply:**

DeltaNet/KDA/MesaNet optimize the *state update* — the compressor. All four (incl. linear attention) are "silent-loss" systems: a fixed-size state with no external record, where what is lost cannot even be enumerated. The literature's quality axis is fidelity (perplexity, recall benchmarks like MQAR). But fidelity ≠ integrity: no current system can answer "prove that memory item m was in your state at time t, and that nothing else was lost." RVA supplies exactly that: a *verifiable external substrate* that (i) pins state checkpoints hash-addressed, (ii) makes any pin recomputable by third parties from the substrate alone, (iii) turns loss into an explicit, gated event (authorized-retired requires explanation; unexplained loss fails the gate), (iv) enables involuntary return of suppressed content.
